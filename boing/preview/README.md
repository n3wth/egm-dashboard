# Local preview

Run `node boing-preview/server.mjs` and open `http://127.0.0.1:4178/`.
Set `BOING_PREVIEW_PORT` to use another port. The server binds only to loopback.

This preview uses fictional workspaces and metrics. It has no sign-in, real
provider connections, stored user data, or ability to make changes. It is not a
staging deployment or a test of the production authorization boundary.
